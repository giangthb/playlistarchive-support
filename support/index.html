Support

Help with importing audio, organizing playlists and local playback.

Import audio

In Library, choose Import Audio, select a supported non-DRM audio file in Apple's system file picker, and confirm the selection. A&F Playlist copies the selected file into its private app container so it remains available offline.

Organize playlists

Create a playlist from the Playlists screen, then add tracks from your library. You can rename, reorder or remove playlist entries without deleting the underlying imported file.

Playback troubleshooting

If a track is unavailable, confirm that the import completed and that your device has enough free storage. For background playback, start a track before locking the device, then use Now Playing or system media controls.

Legacy downloads

Version 2.0 does not automatically expose or play downloads made by older versions. If matching stale files are found, Settings shows their count and offers an explicit confirmation before removal.

Contact
